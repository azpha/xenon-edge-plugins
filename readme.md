# xenon-edge-plugins

My own personal Xenon Edge plugins. Mostly Cyberpunk themed to fit in with the rest of my setup!

## How to use

Check the latest release for all the .icueplugin files. All you need to do is download these and import them using iCUE.

## Development

To add a new package, simply create a folder in `./packages` and use the icuewidget-cli to scaffold a project. Then, when you want to test, package with either the Python script at the root of the project or `icuewidget package` in the package folder.
